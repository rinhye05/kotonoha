# ことのは · Kotonoha

좋아하는 일본 노래를 종이 노트처럼 천천히 옮겨 적는 가사 필사 사이트입니다.

- 24명 가수의 76곡 목록, 가수별 분류와 검색
- 일본어 원문과 한국어 발음 / 한국어 번역 모드
- 한국어 Gaegu, 일본어 Yomogi 손글씨 폰트
- 화이트·다크 테마와 연보라색 포인트
- 곡별 가사 직접 입력, 필사 내용 자동 저장, PNG 이미지 내려받기

Mrs. GREEN APPLE 14곡에는 사용자가 제공한 일본어 원문·한국어 발음·한국어 번역이 기본으로 포함됩니다. 문장부호와 보이지 않는 제어 문자는 제거하고 공백과 일본어 장음은 유지했습니다. 다른 가수의 곡은 각 곡의 ‘가사 담기’에서 직접 입력할 수 있습니다. 직접 만든 창작 예시 3곡으로 필사를 체험할 수 있습니다.

## GitHub Pages

이 폴더의 파일을 공개 저장소의 `main` 브랜치 최상위에 올립니다. 저장소의 **Settings → Pages**에서 **Deploy from a branch**, **main**, **/(root)**를 선택하고 저장하면 GitHub Pages가 사이트를 배포합니다.

빌드나 패키지 설치가 필요 없는 HTML/CSS/JavaScript 사이트입니다. `index.html`, `app.js`, `catalog.js`, `lyrics.js`는 같은 폴더에 있어야 합니다.

## 저장과 개인정보

직접 입력하거나 편집한 가사와 필사 내용은 해당 브라우저의 `localStorage`에 저장됩니다. 서버, GitHub 저장소, 다른 방문자에게 전송되지 않습니다. 다른 기기나 브라우저에는 동기화되지 않으며 브라우저 데이터를 지우면 작성 내용도 사라집니다. 일본어 필사 입력칸 아래에서도 한국어 번역을 볼 수 있습니다. ‘이미지 저장’ 버튼으로 원문, 번역, 직접 쓴 필사와 가수·곡명, 저장한 날짜·시간을 담은 PNG 이미지를 내려받을 수 있습니다. 긴 가사는 여러 장으로 나눠 저장됩니다.

Google Fonts에서 Gaegu와 Yomogi 웹폰트를 불러옵니다.

## 휴대폰 사용

휴대폰에서는 상단의 곡 바꾸기를 눌러 책장을 펼칩니다. 곡을 선택하면 책장이 닫히고 필사 영역으로 이동합니다. 큰 터치 버튼, 긴 가사 줄바꿈, 화면 높이에 맞는 가사 편집창, 가로 세로 전환 시 필사 입력창 높이 조절을 지원합니다. `responsive.css`를 다른 사이트 파일과 함께 배포해야 합니다.
