# ことのは · Kotonoha

좋아하는 일본 노래를 종이 노트처럼 천천히 옮겨 적는 가사 필사 사이트입니다.

- 24명 가수의 76곡 목록, 가수별 분류와 검색
- 일본어 원문과 한국어 발음 / 한국어 번역 모드
- 한국어 Gaegu, 일본어 Yomogi 손글씨 폰트
- 화이트·다크 테마와 연보라색 포인트
- 코드에서 관리하는 가사, 필사 내용 자동 저장, PNG 이미지 내려받기

Mrs. GREEN APPLE 14곡과 사용자가 제공한 추가 문서의 21곡, 총 35곡에 일본어 원문·한국어 발음·한국어 번역이 기본으로 포함됩니다. 추가된 가수는 Kanaria, Porno Graffitti, Yuuri, back number, Tani Yuuki, Hump Back, King Gnu, Novelbright, Tatsuya Kitani, Vaundy, tuki., Yuika, niki입니다. 추가 문서의 가사와 문장부호는 유지하고 보이지 않는 제어 문자는 정리했습니다. 문서에 발음이나 번역이 없는 영어 구절은 원문으로 표시합니다. 가사의 추가·수정은 `lyrics.js`에서 관리합니다. 사이트에는 가사 추가·편집 기능이 없습니다. 직접 만든 창작 예시 3곡으로 필사를 체험할 수 있습니다.

## GitHub Pages

이 폴더의 파일을 공개 저장소의 `main` 브랜치 최상위에 올립니다. 저장소의 **Settings → Pages**에서 **Deploy from a branch**, **main**, **/(root)**를 선택하고 저장하면 GitHub Pages가 사이트를 배포합니다.

빌드나 패키지 설치가 필요 없는 HTML/CSS/JavaScript 사이트입니다. `index.html`, `app.js`, `catalog.js`, `lyrics.js`, `export.js`는 같은 폴더에 있어야 합니다.

## 저장과 개인정보

필사 내용과 화면 설정은 해당 브라우저의 `localStorage`에 저장됩니다. 서버, GitHub 저장소, 다른 방문자에게 전송되지 않습니다. 다른 기기나 브라우저에는 동기화되지 않으며 브라우저 데이터를 지우면 작성 내용도 사라집니다. 일본어 원문 → 발음 → 한국어 번역 → 필사 입력칸 순서로 볼 수 있습니다. ‘이미지 저장’ 버튼으로 원문, 번역, 직접 쓴 필사와 가수·곡명, 저장한 날짜·시간을 담은 PNG 이미지를 내려받을 수 있습니다. 긴 가사는 여러 장으로 나눠 저장됩니다.

Google Fonts에서 Gaegu와 Yomogi 웹폰트를 불러옵니다.

## 휴대폰 사용

휴대폰에서는 상단의 곡 바꾸기를 눌러 책장을 펼칩니다. 곡을 선택하면 책장이 닫히고 필사 영역으로 이동합니다. 큰 터치 버튼, 긴 가사 줄바꿈, 화면 높이에 맞는 가사 편집창, 가로 세로 전환 시 필사 입력창 높이 조절을 지원합니다. `responsive.css`를 다른 사이트 파일과 함께 배포해야 합니다.

## 가사 추가·수정

기존 곡의 가사는 `lyrics.js`의 `bundledLyrics`에서 해당 곡 ID를 찾아 수정합니다. 각 줄은 `[일본어 원문, 한국어 발음, 한국어 번역]` 순서입니다. 새 곡은 `catalog.js`의 `artistCatalog` 목록 끝에 추가하고, 생성되는 `catalog-가수인덱스-곡인덱스` ID에 맞춰 가사를 등록합니다. 기존 곡 ID가 바뀌지 않도록 기존 목록 중간에 삽입하거나 순서를 바꾸지 않습니다. 변경 파일을 GitHub에 반영하면 사이트에도 적용됩니다.

이전에 브라우저에서 편집한 가사는 표시하지 않고 코드의 가사를 사용합니다. 기존 브라우저 데이터는 보존합니다.
